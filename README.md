# RAPARTHI MAHESH DIGITAL STUDIO

Official website for **RAPARTHI MAHESH DIGITAL STUDIO**, specializing in fine art wedding photography, cinematic films, traditional portraits, and bespoke events.

## Features
- **Curated Visual Archive**: Responsive photo gallery across portraits, landscapes, events, and weddings with filter controls and full-screen lightbox.
- **Cinematic Video Highlights**: Showcase for cinematic wedding films and highlight reels.
- **Interactive Session Booking**: Guided reservation flow with deposit calculation and booking receipt generation.
- **Studio Biography**: Overview of artistic legacy and philosophy.
- **Direct Connect**: Studio flagship location in Suryapet, direct phone, WhatsApp messaging, and inquiry forms.

## Tech Stack
- Semantic HTML5, CSS3 (Custom Properties & Flex/Grid), Vanilla JavaScript (ES6+)
- Zero external build dependencies
- Fast static site hosting ready (Netlify, Vercel, GitHub Pages)
